Breathing Space PWA package

Upload index.html, manifest.webmanifest, sw.js, and the icons folder to the root of your Breathing Space GitHub repository. Keep filenames and folder paths exactly as supplied. GitHub Pages must be enabled on the branch that contains these files.

After Pages finishes publishing, open the GitHub Pages URL in Safari or Chrome. On iPhone, choose Share > Add to Home Screen. On Android, use the browser's Install app or Add to Home screen option. Open once online to cache the app for later offline use.

The Collin College logo is embedded in index.html. The icons folder is needed for the Home Screen icon. When releasing future versions, change the CACHE name in sw.js (for example, breathing-space-v2) so installed copies refresh their offline files.

The screen-awake preference depends on browser and device support. Audio and animation may pause when the app is backgrounded or the device locks.
